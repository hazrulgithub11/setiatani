# Frontend

Starter frontend with:

- React 19 + TypeScript
- Vite 8
- React Router 7
- Tailwind CSS v4
- Utility stack (`clsx`, `tailwind-merge`, `class-variance-authority`)

## Run locally

```bash
pnpm install
pnpm dev
```

## Available scripts

- `pnpm dev` - start dev server
- `pnpm build` - type-check and build production assets
- `pnpm preview` - preview production build
- `pnpm lint` - run eslint
